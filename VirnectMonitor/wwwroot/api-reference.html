공통 규칙

powercode (서버 전원)

1켜짐
0꺼짐
Prometheus up 메트릭 기준. 꺼진 서버도 잡힘.

operationCode (장비요약 운영상태)

0전원없음
1클린
2경고
3위험
Make&View 장비요약 카드용 종합 상태.

status (지표 상태, AR용)

1클린(정상)
0경고
-1위험
= 1 − levelCode

levelCode (상세 JSON)

0클린
1경고
2위험
Make&View 지표 API는 전원없음을 포함해 0~3으로 변환.

공통 값

서버server-01 ~ server-04
지표cpu, memory, disk, disk_io, net_recv, net_sent
시간updatedAt(Unix초) + updatedAtText(KST 문자열)

화면 페이지 (HTML)

GET/server 로그인 필요

전체 대시보드 (4대 + 전체그래프 탭). 미인증 시 /auth/start로 리다이렉트.

GET/server-01 ~ /server-04 로그인 필요

서버 1대 전용 대시보드(server.html). 임계선 그래프 포함.

모니터링 데이터 API

GET/api/health

백엔드 상태 + 마지막 수집 시각 + 서버 목록.

{
  "ok": true,
  "lastUpdated": 1781257155,
  "lastUpdatedText": "2026-06-12 18:39:15",
  "lastError": null,
  "prometheusUrl": "http://prometheus:9090",
  "servers": ["server-01", "server-02", "server-03"]
}
GET/api/metrics

지표 정의와 임계치(warn/danger). 프론트 표시용.

GET/api/status

모든 서버 현재 스냅샷 (웹 대시보드 메인). servers는 켜진 서버만.

{ "ts": 1781257155, "tsText": "2026-06-12 18:39:15", "servers": { ... } }
GET/api/server/{server} 전원·알림수 통합

Make&View 장비요약용 짧은 JSON — 전원 on/off + 운영상태 + 확인 필요 요약 + 알림수. 꺼진 서버도 powercode:0으로 응답. 없는 서버는 404.

{
  "server": "server-01",
  "powercode": 1,            // 1 켜짐 / 0 꺼짐
  "operationCode": 3,         // 0 전원없음 / 1 클린 / 2 경고 / 3 위험
  "checkMessage": "CPU 사용률, 디스크 사용률 확인 필요",
  "alertNum": 1              // 이상징후 개수
}
꺼진 서버 예: { "server":"server-04", "powercode":0, "operationCode":0, "checkMessage":"전원 상태 확인 필요", "alertNum":0 }
GET/api/server/{server}/metrics 웹 상세

선택/디버깅용 JSON — 현재 지표 목록과 갱신 시간 포함.

{
  "server": "server-01",
  "powercode": 1,
  "operationCode": 3,
  "checkMessage": "CPU 사용률, 디스크 사용률 확인 필요",
  "alertNum": 1,
  "updatedAt": 1781257155,
  "updatedAtText": "2026-06-12 18:39:15",
  "metrics": {
    "cpu": { "value": 79.5, "display": "79.5%", "levelCode": 1, "status": 0, "unit": "%", ... },
    "memory": { "status": 1, ... },
    ... (disk, disk_io, net_recv, net_sent)
  }
}
GET/api/metric/{server}/{metric}

Make&View 지표 화면용 짧은 JSON. 전원 조건은 powercode, 값 표시는 display, 상태 조건은 levelCode를 연결. levelCode는 0 전원없음 / 1 클린 / 2 경고 / 3 위험.

{ "powercode":1, "display":"79.5%", "levelCode":2 }
GET/api/alert/{server}

서버 종합 심각도 1개 (AR 알림 트리거: value>=2 위험).

{ "server":"server-01", "value":1, "level":"warning", "levelText":"경고" }
GET/api/alert/{server}/issues 신규

서버별 이상징후만(경고·위험) 목록. 정상은 제외, 없으면 빈 배열. 최대 5개.

{
  "server": "server-01",
  "updatedAt": 1781257155,
  "updatedAtText": "2026-06-12 18:39:15",
  "count": 1,
  "alerts": [
    { "metric":"cpu", "name":"CPU 사용률", "value":79.5, "display":"79.5%",
      "levelCode":1, "levelText":"경고", "message":"CPU 사용률 79.5% 경고" }
  ]
}
GET/api/alert

전체 종합 (가장 심각한 서버 기준).

GET/api/history/{server}/{metric}

한 서버·한 지표의 시계열 (그래프용). 쿼리: ?minutes=60&step=15

{ "server":"server-01", "metric":"cpu", "unit":"%", "points": [ [1781257000, 51.5], ... ] }
GET/api/history/{metric}

한 지표의 모든 서버 추이 (대시보드 멀티라인). 쿼리: ?minutes=60&step=15

GET/api/anomalies

이상징후 이력(SQLite). 쿼리: ?limit=100&server=&metric=

GET/api/alerts

레벨 전환 알림 이력(SQLite). 쿼리: ?limit=50&server=. message는 서버별 화면 표시용 한 줄 문구.

[
  { "message":"[15:16:35] CPU 사용률 경고 (83.2%)" }
]

인증 API (로그인 토큰 흐름)

GET/ · /login/start · /auth/start

로그인 진입점. 셋업 안 됐으면 셋업 페이지, 됐으면 로그인 토큰 발급 흐름.

POST/auth/start

로그인 토큰 발급 시작.

GET/setup   POST/setup

최초 관리자 계정 셋업 페이지 / 처리.

GET/login?token={token}

토큰으로 로그인 페이지 표시.

POST/auth/login

로그인 처리 (body: token). 성공 시 /login/result?token=로 이동.

GET/login/result?token={token}

로그인 결과·승인 대기 페이지. JS가 /auth/current-once를 폴링.

GET/auth/status/{token}

토큰 상태 조회 (경로 파라미터).

GET/auth/current?token={token}

현재 인증 상태 조회.

GET/auth/current-once?token={token}

1회용 상태 조회 (결과 페이지 폴링용). Make&View 연결은 숫자 필드 value만 사용.

POST/auth/logout?token={token}

Make&View 로그아웃 버튼용. 요청 body에 문자열 logout을 보내면 해당 세션을 revoked 처리. 토큰을 생략하면 호환 모드에서 최신 승인 세션을 로그아웃.

위치keyvalue필수설명
Query Stringtoken로그인 토큰 문자열권장로그아웃할 세션 지정
Body JSONcommandlogout필수로그아웃 신청 명령
{
  "command": "logout"
}
{
  "token": "{token}",
  "command": "logout"
}
{
  "status": "revoked",
  "value": 1,
  "loggedOut": true
}
GET/auth/sessions?limit=

세션 목록 조회.

GET/auth/login-audits?limit=

로그인 감사 로그 조회.

GET/admin 관리자

세션·로그인 감사 모니터 페이지. 미인증 시 /auth/start로 리다이렉트.
