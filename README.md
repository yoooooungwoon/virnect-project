# virnect-project

## 프로젝트 개요

VIRNECT AR 프로그램 UI 디자인입니다.
사용자 인증 화면과 시스템 모니터링 대시보드 화면을 중심으로 구성되어 있으며, CPU, RAM, DISK, POWER, 온도 등의 시스템 정보를 시각적으로 확인할 수 있는 UI를 설계했습니다.

## 디자인 구성

### 1. 사용자 인증 화면

사용자가 이름과 비밀번호를 입력한 뒤 인증을 진행하는 화면입니다.

주요 구성 요소:

* 사용자 인증 타이틀
* 이름 입력 필드
* 비밀번호 입력 필드
* 인증 하기 버튼

### 2. 시스템 모니터링 화면

시스템 상태를 카드 형태로 확인할 수 있는 대시보드 화면입니다.

주요 구성 요소:

* 좌측 메뉴 영역

  * 일반
  * 그래프
  * 다른 모드
* 시스템 모니터 타이틀
* CPU 온도 카드
* CPU 사용률 카드
* RAM 카드
* DISK 카드
* POWER 카드

### 3. 그래프 화면

각 시스템 지표를 선 그래프 형태로 시각화한 화면입니다.
CPU 온도, CPU 사용률, RAM, DISK, POWER의 상태 변화를 한 화면에서 확인할 수 있도록 구성했습니다.

## 첨부 파일

현재 저장소에는 Figma 원본 파일 및 PDF, PNG, 버넥트 make 디자인 파일이 포함되어 있습니다.

예상 파일 구성:

```txt
design/
│
├─ README.md
│ 
├─ figma/
│  └─ virnect-project.fig
│  
├─ pdf/
│  ├─ 인증 화면.pdf
│  ├─ 모니터링 화면.pdf
│  └─ 그래프.pdf 
│
├─ png/
|  ├─ 인증 화면.png
|  ├─ 모니터링 화면.png
|  └─ 그래프.png
|
└─ make/
   ├─ UI 테스트.mars
   └─png/
      └─ 메이크 파일에 사용된 png 이미지(총 20개)
```

## 작업 목적

이 프로젝트는 시스템 모니터링 UI의 기본 화면 구조와 시각적 스타일을 제안하기 위한 디자인 결과물입니다.
